# Hinweise für Claude in diesem Projekt

## Dokumente für Omar (Anleitungen, Hilfen, Übersichten)
- Keine nackten .md- oder .txt-Dateien abgeben: Sie öffnen sich unter Windows im Editor und wirken «reingedrückt».
- Stattdessen eine schön gestaltete **HTML-Datei** (Doppelklick öffnet sie im Browser) oder auf Wunsch PDF.
- Gestaltung: viel Abstand (Zeilenabstand ca. 1.6, Luft zwischen Abschnitten), klare Überschriften,
  nummerierte Schritte, kurze Absätze, Hinweis-/Warnkästen farbig abgesetzt, gut lesbar auf PC und Handy.
- Oben Titel, Version und Datum/Uhrzeit (Schweizer Zeit), damit die aktuelle Fassung erkennbar ist.
- Sprache: Deutsch, Schweizer Schreibweise («ss»), einfach und ohne Fachjargon.
- Gilt für alle künftigen Dokumente, nicht nur die Tresor-Anleitung.
